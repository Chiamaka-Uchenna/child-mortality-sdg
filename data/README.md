# Data

Raw data is not committed. The notebook downloads it into `data/raw/` on first run.

Source: [World Development Indicators](https://databank.worldbank.org/source/world-development-indicators) (World Bank, CC BY 4.0), downloaded through the public API. Sixteen indicators for 196 countries from 2000 to 2024. Mortality estimates are from the UN Inter-agency Group for Child Mortality Estimation.
